# Breathway

> 🤖 **Note:** the initial project scaffold in this repository (structure,
> boilerplate source, resources, and docs) was generated by an AI coding
> agent (GitHub Copilot CLI) from the project owner's requirements. See
> `AGENTS.md` for details and git history for the originating commit.

A Garmin Connect IQ watch app that guides you through a breathing exercise
(default: 4-1-6-1 — 4s in, 1s hold, 6s out, 1s hold) with an animated circle
and phase cues.

- Package id: `be.melxaco.breathway`
- App type: Watch App
- Language: Monkey C
- Initial target devices: fenix7, fenix7s, fr265, fr965, fenix8solar51mm

## Prerequisites

1. Install the **Garmin Connect IQ SDK** via the SDK Manager:
   https://developer.garmin.com/connect-iq/sdk/
2. Install the **Monkey C** extension for VS Code (recommended), or use the
   `monkeyc` / `monkeydo` / `sdkmanager` CLI tools directly.
3. Generate a developer signing key (one-time, per machine). The Monkey C
   VS Code extension can generate one for you, or use `openssl` directly:
   ```bash
   openssl genrsa -out developer_key.pem 4096
   openssl pkcs8 -topk8 -inform PEM -outform DER -in developer_key.pem \
     -out developer_key -nocrypt
   ```
   `developer_key` is gitignored — never commit it.

## Build

Build artifacts go in `build/` (gitignored), named with the current project
version from the `VERSION` file (`major.minor.patch`, e.g. `0.3.0`):

```bash
monkeyc -f monkey.jungle -d fenix7s -o "build/breathway-$(cat VERSION).prg" -y developer_key
```

## Run in simulator

```bash
# Start the Connect IQ simulator once, then:
monkeydo "build/breathway-$(cat VERSION).prg" fenix7s
```

Or use the VS Code Monkey C extension's "Run Current Project in Simulator"
command — `.vscode/launch.json` is preconfigured for the `fenix7s` device
(targeting a stable `build/breathway.prg`, separate from the version-tagged
builds above).

## Run on a physical device (macOS)

Build for your actual device (e.g. `-d fenix7` instead of `-d fenix7s`), then
copy the resulting `.prg` from `build/` into `GARMIN/APPS/` on the watch when
it's connected via USB.

**Note for macOS:** some Garmin watches (Fenix 7 and similar models with
onboard music storage) can connect in either **"Garmin"** or **"MTP"** USB
mode, selectable on the device. macOS has no built-in MTP support, so in MTP
mode no drive will mount, even though the connection itself works fine
(charging, permission prompts, etc.) — it just won't show up in Finder.
Either switch the watch to **"Garmin" mode** (simplest — mounts as a normal
drive), or if you need to stay in MTP mode, install an MTP client:

```bash
brew install --cask android-file-transfer
```

then use its file browser to copy the `.prg` into `GARMIN/APPS/`.
